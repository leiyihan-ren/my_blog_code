开启后，GitHub 仓库内容与后台数据合并展示：后台发布/编辑的内容优先，仓库新增内容自动补充
📝 双来源合并说明：
• 文章 / 音乐 / 时间线 / 相册：GitHub 仓库内容与后台数据合并展示，不再是二选一
• 后台发布新文章 → 直接出现在合并列表中；编辑仓库文章 → 生成后台版本并覆盖仓库版本
• 后台删除仓库文章 → 记录删除墓碑，仓库更新后也不会复活
• 文章：仓库 posts/ 文件夹的 .md 文件（支持 front matter）；音乐：music.json 或 music/ 文件夹；时间线：timeline.json；相册：photos/ 文件夹
• 数据每 5 分钟自动刷新；jsDelivr CDN 可能有最多约 12 小时的缓存延迟，追求实时可关闭 CDN 加速
• GitHub 连接不稳定时自动切换镜像源，并优先使用缓存内容，站点不会空屏
