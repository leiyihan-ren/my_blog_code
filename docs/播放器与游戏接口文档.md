# 第一部分 · 音乐播放器（components/music-player.js）

## 1. 组件形态

- **加载方式**：8 个页面 `<script src="components/music-player.js" defer>`；admin 后台不装载
- **隔离方式**：IIFE + `"use strict"`，不向 window 暴露任何符号（除可选的 `window.showToast` 复用检测）
- **自注入**：运行时把播放器 DOM（CSS + HTML 模板字符串）append 到 `document.body` 末尾
- **音频引擎**：原生 `new Audio()`，`preload="metadata"`

## 2. 状态模型（模块级闭包变量）

```
┌────────────────────────────────────────────────────────────┐
│ playlist[]         歌曲数组（loadMusic 时按 url 合法性过滤）  │
│ currentIdx         当前索引（loadSong 内取模归一化）          │
│ loadToken          切歌竞态令牌（自增，过期回调直接 return）   │
│ consecutiveErrors   连续加载失败计数（防全部失效时无限切换）    │
│ pendingSwitch      失败后「自动切下一首」定时器句柄             │
│ seeking            进度条拖动中（拖动期间忽略 timeupdate）      │
│ lastProgressUpdate 进度刷新节流时间戳                          │
│ volumeBeforeMute   静音前音量（恢复用）                        │
│ playMode           listLoop | singleLoop | shuffle | sequence │
│ shuffleOrder[]     随机模式播放顺序（Fisher-Yates 洗牌）       │
│ shufflePos         随机模式播放位置游标                        │
└────────────────────────────────────────────────────────────┘
持久化（localStorage，safeStorage 包裹）：
  mp_mode    播放模式        mp_volume  音量 0~1
  mp_hidden  "1" = 收起态
```

### 状态机：播放/加载/错误三线并发

```
用户操作 / 自动触发
   │
   ▼
loadSong(idx, autoplay)
   ├─ clearTimeout(pendingSwitch)          ← 取消未触发的失败切换
   ├─ myToken = ++loadToken                ← 竞态防护：旧加载的任何回调先查 token
   ├─ currentIdx = 取模归一化(idx)
   ├─ audio.src = song.url                 ← 浏览器开始加载
   ├─ 重置进度 UI（bar/buffer/time/duration/ data-ready）
   ├─ 渲染封面（https 校验 → img.onerror 回退 🎵，同样查 token）
   ├─ renderPlaylist() + updateMediaSession()
   └─ autoplay ? audio.play() : syncPlayUI()
                     │
        play() reject │（自动播放策略）
                     ▼
              显示「浏览器阻止了自动播放」提示

audio error 事件 ──► consecutiveErrors++
   └─ < 阈值：pendingSwitch = setTimeout(自动切下一首, 延迟)
   └─ ≥ 阈值：放弃自动切换（防无限跳）

audio playing 事件 ──► consecutiveErrors = 0
audio ended 事件 ──► pickNextIndex() → loadSong(…, true)（顺序模式末尾则停止）
```

## 3. 播放模式矩阵（`pickNextIndex` / `pickPrevIndex`）

| 模式 | 图标 | 下一首 | 上一首 | 末尾行为 |
|------|------|--------|--------|----------|
| `listLoop` 列表循环 | 🔁 | `(idx+1) % len` | `(idx-1+len) % len` | 循环 |
| `singleLoop` 单曲循环 | 🔂 | `idx` 本身 | `idx` 本身 | — |
| `shuffle` 随机 | 🔀 | `shuffleOrder[++pos]`，耗尽重洗 | `shuffleOrder[--pos]`，越界退回顺序 | 重洗牌继续 |
| `sequence` 顺序 | ➡️ | `idx+1`，越界返回 -1 | `(idx-1+len) % len` | 暂停 + toast「已播完」 |

单元素列表特判：任何模式下一首/上一首都是 `0`。

## 4. 键盘快捷键（文档级 keydown，带四级让位链）

```
让位链（任一条命中即整条 switch 不执行）：
  1. window.GameCore.isGameRunning() === true   → 游戏进行中，按键归游戏
  2. document.querySelector(".lightbox.active")  → 相册灯箱打开，方向键归灯箱
  3. 焦点在 INPUT/TEXTAREA/SELECT/BUTTON/contentEditable → 不抢用户操作
  4. ctrl/meta/alt 组合键                       → 不拦截浏览器快捷键

生效映射：
  Space        播放/暂停（togglePlay，preventDefault 防页面滚动）
  ArrowLeft    快退 5s（seekBy(-5)）
  ArrowRight   快进 5s（seekBy(+5)）
  Shift+←/→    上一首 / 下一首（prevSong/nextSong）
  ArrowUp/Down 音量 ±0.05（同步 localStorage）
  M            静音开关（toggleMute）
```

## 5. 进度条拖动（Pointer Events）

```
pointerdown → seeking = true；pendingSeek = null（本次拖动尚无有效目标）
              progress.classList.add("mp-seeking")（轨道变粗反馈）
pointermove → 按 getBoundingClientRect 换算比例 → pendingSeek = 秒数
              只更新 UI，不写 audio.currentTime（防抖动）
pointerup/cancel → seeking = false
              pendingSeek !== null → audio.currentTime = pendingSeek
              （判 null 而非 >0：允许拖到 0 秒）
timeupdate 事件 → seeking 为 true 时整条忽略（防拖动与播放进度互搏）
```

## 6. 系统媒体控制（Media Session）

```
loadSong → updateMediaSession(song)
   ├─ metadata = new MediaMetadata({ title, artist, album: "我的博客", artwork })
   ├─ setActionHandler("play"/"pause"/"previoustrack"/"nexttrack", …)
syncPlayUI → navigator.mediaSession.playbackState = "playing" | "paused"
```

锁屏/通知栏/耳机按键由此获得完整控制；特性检测缺失时静默跳过。

## 7. 对外接口（其他组件可依赖的部分）

| 接口 | 类型 | 说明 |
|------|------|------|
| DOM：`#mpPlayer` / `.mp-player` | 元素 | 播放器根节点；`.mp-hidden` = 收起态（translateY 露出 28px 把手） |
| DOM：`#mpPlaylist.active` | 类名 | 播放列表展开态 |
| `window.showToast(msg)` | 函数（可选） | 存在则复用页面级 toast，不存在自降级（2000ms） |
| `window.GameCore.isGameRunning()` | 查询 | **播放器调用游戏**：游戏进行中让位键盘 |
| `.lightbox.active` | 类名查询 | **播放器避让相册**：方向键不双触发 |

> 播放器**不向 window 暴露任何 API**——这是刻意设计：任何页面只需一个 `<script defer>` 即获得完整播放器，无初始化调用、无版本兼容问题。

## 8. 数据契约

```
输入：GET /api/music → Song[]
  Song = { id: string, title: string, artist: string,
           url: string(必须 http/https), cover: string(可选, http/https) }
过滤：loadMusic 时剔除无 url / 非 http(s) 的条目
输出：POST /api/game/score/:gameId 与本组件无关；播放器无写端点
```

# 第二部分 · 游戏大厅（components/game-core.js + components/games/*.js）

## 1. 架构总览

```
games.html（舞台 DOM + 装载脚本）
   │
   ├─ components/game-core.js ──► window.GameCore（单例，IIFE 返回 API 对象）
   │                     ├─ BaseGame      基类：生命周期 + 计时器/监听登记
   │                     ├─ Input         键盘 / 滑动 / 虚拟方向键 / 点按
   │                     ├─ Stage         舞台控制 + 个人最佳
   │                     ├─ Rank          排行榜加载/渲染/提交
   │                     └─ Registry      游戏注册表（Map）
   │
   ├─ components/games/snake.js    ─┐
   ├─ components/games/breakout.js  ├─ 装载即执行 register(id, {meta, create})
   ├─ components/games/g2048.js     │   （core 不 import 子游戏，子游戏依赖 core）
   ├─ components/games/memory.js    │
   └─ components/games/mines.js   ─┘
```

**注册表用 `Map` 而非对象**：游戏 id 含 `"2048"` 纯数字键，普通对象的整数键枚举会排到最前，导致卡片/排行榜顺序错乱。

## 2. 子游戏注册接口

```js
// 每个游戏文件末尾：
GameCore.register(id, {
  meta: {
    id:    "snake",            // 唯一键（排行榜 KV 分片同键）
    name:  "贪吃蛇",            // 卡片/舞台/排行榜显示名
    icon:  "🐍",               // emoji 图标
    desc:  "吃掉食物变长……",    // 卡片副标题
    tips:  "方向键或 WASD……",   // 操作说明（HTML，注入 #tips）
    unit:  "分",               // 分数单位（scoreText 默认拼接）
    scoreLabel: "分数",        // 计分板标签
  },
  create: () => new SnakeGame(),  // 工厂：每次打开游戏创建新实例
});
```

`register` 内部把 `meta` 拍平到条目上（`g.name`/`g.icon` 直接可读），渲染层不层层 `.meta`。

## 3. BaseGame 生命周期

```
openGame(id)
   │  current.destroy()（旧实例：清计时器 + 解绑全部监听）
   ▼
create() → current = def.create()
   │
   ▼
mount(root, api)          ← 子类重写必须先 super.mount(root, api)
   │  api = { overlay, overlayTitle, overlayScore, overlayText, overlayBtn,
   │          score, extra, tips, onStart, onPause, onResume, onStop,
   │          onGameOver(score), toast }
   │  内置：visibilitychange → 切后台自动 pause
   ▼
start()                   ← 由「开始」按钮触发
   │  api.onStart() → running = true
   │  clearTimers()   ← 重开必须先清（否则贪吃蛇双循环 / 扫雷叠加秒表）
   │  overlay 隐藏 → reset()（子类重置状态）→ loop()（子类启动主循环）
   ▼
running ──pause()──▶ clearTimers + onPause + overlay「已暂停/继续」
       ──resume()─▶ running = true + overlay 隐藏 + loop()
   ▼
gameOver(text)            ← 子类调用
   │  幂等保护：!running && lastScore === score → 直接 return
   │  clearTimers + lastScore = score + onGameOver(score) + onStop
   │  overlay「游戏结束/再来一局」+ 新纪录 toast + 解锁提交按钮
   ▼
destroy()                 ← 切游戏/离开：clearTimers + offAll
```

### 子类必须/可选重写

| 方法 | 必须 | 说明 |
|------|------|------|
| `reset()` | ✅ | 重置棋盘/状态（框架已负责清计时器） |
| `loop()` | ✅ | 启动主循环（无动画的游戏给空实现） |
| `mount(root, api)` | 可选 | 建 DOM/绑输入；**重写必须先 `super.mount()`** |
| `scoreText()` | 可选 | 默认 `score + " " + (meta.unit \|\| "分")`（扫雷显示剩余雷数） |

## 4. 计时器与监听登记（框架核心价值）

```js
// 子类禁止直接用 setTimeout/setInterval/rAF/addEventListener，
// 一律走框架登记版，pause/destroy 自动全清：
this.after(ms, fn)          // setTimeout（触发后自动出册）
this.every(ms, fn)          // setInterval
this.rafLoop(fn)            // rAF 循环：每帧查 running，自动续排/终止
this.raf(fn)                // 单帧 rAF
this.on(target, type, fn)   // addEventListener（destroy 时 offAll）

clearTimers()  // pause/start/gameOver 时调用
offAll()       // destroy 时调用
```

> **踩坑记录**：早期扫雷把计时器注册在 `reset()`，重开叠加多个 interval；贪吃蛇重开出现双循环（速度翻倍）。根因是原始计时器不在框架管辖内。修复即上表。

## 5. 输入适配层

| 方法 | 覆盖 | 要点 |
|------|------|------|
| `bindKeys(map)` | 键盘 | 忽略 INPUT/TEXTAREA/SELECT/contentEditable；**不忽略 BUTTON**（鼠标点过开始后焦点在按钮上，忽略会吞掉方向键）；已映射键 preventDefault 防滚动；addEventListener 不劫持 onkeydown（避免与播放器互踩） |
| `bindSwipe(el, handler)` | 滑动 | 超 24px 触发；需配合 CSS `touch-action:none`（2048 曾因缺失连带滚页面） |
| `buildDpad(handler)` | 虚拟方向键 | 返回 DOM；touchstart 即触发 + 300ms 后 120ms 间隔连发；**长按计时器必须走 this.after/this.every**（否则切游戏后幽灵操作） |
| `bindTap(el, handler)` | 点按 | 事件委托：`[data-tap]` → handler(value, el, e) |

## 6. Stage 舞台 API（`window.GameCore` 导出全表）

| API | 签名 | 说明 |
|-----|------|------|
| `openGame` | `(id) → void` | 打开游戏：destroy 旧的 → create → mount → 显示 overlay |
| `renderGameGrid` | `() → void` | 渲染游戏卡片网格（tabindex=0 + role=button + Enter/Space 键盘可开） |
| `loadRanks` | `async ()` | GET /api/game/scores → 渲染 tabs + 榜单 |
| `submitScore` | `async (gameId, score)` | 昵称 prompt（≤12 字，localStorage 记忆）→ POST → toast 排名 |
| `getBest` / `setBest` | `(id) → number` / `(id, v)` | 个人最佳（localStorage `game-best-<id>`，safeStorage 包裹） |
| `getNick` | `() → string` | 排行榜昵称（`game-nickname`） |
| `isGameRunning` | `() → boolean` | **播放器依赖此查询让位键盘** |
| `bindStageButtons` | `() → void` | 绑定开始/重开/暂停/提交/昵称按钮（点击后 blur 防空格复触） |
| `currentGame` | `() → instance\|null` | 测试/调试用（业务代码勿依赖） |
| `toast` | `(msg) → void` | 页面级提示 2.2s |
| `fitCanvas` | `(canvas, w, h) → ctx` | 高分屏适配：DPR≤3 缩放，逻辑坐标仍是 CSS 像素；CSS `max-width:100%; height:auto` 窄屏等比缩小，指针映射用 getBoundingClientRect 换算 |
| `escapeHtml` / `escapeAttr` / `$` | 工具 | 属性上下文必须用 `escapeAttr`（转义引号） |

## 7. 排行榜数据契约

```
GET  /api/game/scores → { [gameId]: Score[] }
POST /api/game/score/:gameId  body: { name: string(≤12), score: number(>0) }
     → { success: true, rank: number } | { error: string }
Score = { name: string, score: number, date: string(ISO) }
```

前端提交前置校验：`score <= 0` 拒绝；昵称 prompt 校验 ≤12 字。服务端另行校验（防绕过）。

## 8. 五款游戏差异表

| 游戏 | 主循环 | 输入 | 特有机制 |
|------|--------|------|----------|
| 贪吃蛇 | `every(速度)` 步进 | 键盘/滑动/Dpad | 三档速度 + 随得分加速（有下限）；转向输入缓冲（防快速连按自杀转向） |
| 打砖块 | `rafLoop` | 鼠标/触屏/方向键 | 3 条命；挡板击球点决定反弹角（正中强制最小水平分量防垂直锁死）；侧面碰撞水平反弹防穿透 |
| 2048 | 事件驱动（无循环） | 键盘/滑动 | 移动前位置快照 diff：仅新落/合并格播动画；合并标记 `mergedCells` |
| 记忆翻牌 | 事件驱动 | 点击/键盘 | roving tabindex（方向键移焦 + Enter/空格翻牌）；翻回计时走 `this.after`；暂停立即翻回对比中的两张（防恢复后 busy 卡死） |
| 扫雷 | `every(1000)` 秒表 | 左键/右键/长按 | **首击安全**（首击才布雷且保证首击及邻居无雷）；一次性建格 + 原地更新 class（防 innerHTML 重建吞动画）；计时器在 `loop()` 注册 |
