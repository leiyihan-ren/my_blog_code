## 五、部署提示（交付包使用方法）

1. 解压 zip 后，整个目录即为 Cloudflare Pages 项目根
2. `wrangler.toml` 已配置 KV 绑定（部署前按 README「部署」章节绑定 KV 命名空间）
3. **必须设置管理员密码**（`wrangler secret put ADMIN_PASSWORD`），否则后台默认密码可被猜测
4. 本地预览：`python3 -m http.server 8899` 后访问各页面（无 KV 时 API 降级，页面框架与 UI 完整可见）

## 六、已知限制（如实告知）

- 静态预览模式下 `/api/*` 不可用：文章/相册/音乐等动态内容为空态，属预期（需 KV 后端）
- 相册图片依赖 GitHub 仓库配置（后台开启同步并关联仓库后自动出现）
- admin 后台在无 KV 环境下无法登录（服务端校验）
- 以上限制均为部署形态差异，非代码缺陷；全部 UI/交互/a11y 结论在静态模式下已验证
